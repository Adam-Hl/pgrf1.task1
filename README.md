# Úloha 1: Rasterizace úsečky a n-úhelníku
- Levým tlačítkem myši klikněte na plátno a vytvořte první bod úsečky nebo n-úhelníku.
- Levým tlačítkem myši klikněte na plátno a vytvořte druhý bod úsečky nebo další vrchol n-úhelníku.
- Pravým tlačítkem myši klikněte na plátno a dokončete úsečku nebo n-úhelník.
- Stiskněte klávesu "C" pro vymazání plátna.
